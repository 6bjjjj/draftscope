# DraftScope v0.1.0 — Research Preview

An Apache-2.0 Python toolkit for reproducible NVIDIA inference experiments, including an optional prefix-conditioned target-head extension.

## Included

- Transformers + SDPA baseline with capability-based FP16/BF16 selection.
- A pinned Linux vLLM INT4 + DFlash2 preset.
- Experimental W8A16 coarse scoring, candidate refinement and prefix-conditioned dense fallback selected through CUDA conditional graphs.
- Frozen model revisions and input hashes, atomic partial-result saving, explicit activation status and a CLI time-limit supervisor.
- Separate request/decode timing, original research evidence and a sourced prior-work comparison.
- English and Arabic documentation and a GPU report template.

## Evidence and scope

The original A100 head study reduced dense-fallback calls from 33 to 9 across 78 captured calls. Its compiled component reduced head wall time by 18.95%; the later whole-model V8 experiment reduced request latency by 0.922%, below its frozen admission threshold. These are different experiments with different numerical guards.

The packaged GPU adapters and portable extension still need device integration testing. Historical GPU validation is A100-only, independent task-quality acceptance is unknown, and the extension is off by default. CPU CI covers configuration, result handling, worker lifecycle, evidence integrity and packaging on Linux/Windows with Python 3.11/3.13. It does not validate CUDA behavior.

INT4, DFlash2, Marlin and coarse/refine selection are existing techniques. See the [mechanism comparison](https://github.com/6bjjjj/draftscope/blob/main/docs/related-work.md) for the scope of this implementation.

## Try the package without a GPU

Download the wheel below, then:

```sh
python -m pip install draftscope-0.1.0-py3-none-any.whl
draftscope plan
```

Planning does not download weights or allocate GPU memory. Follow the [README](https://github.com/6bjjjj/draftscope#install) to install the relevant GPU backend in a separate environment.

We welcome [reproducible compatibility reports and numerical reviews](https://github.com/6bjjjj/draftscope/blob/main/CONTRIBUTING.md). The attached SHA256 file covers the wheel and source distribution. No model weights are distributed.
