# DraftScope

مكتبة لتجارب الاستدلال على كروت **NVIDIA فقط**، مع قياس واضح للسرعة، وحفظ النتائج، وسقف زمني للتشغيل.

- المسار العام يستخدم Transformers ويختار FP16 أو BF16 حسب قدرة الكرت.
- مسار vLLM اختياري على Linux، مع إعداد INT4 + DFlash2 مثبت الإصدارات.
- تحسين V8 التجريبي غير محصور باسم كرت: يتفعّل اختيارياً حسب قدرات الكرت، وتوافق CUDA، والذاكرة، ونتيجة الفحص المبدئي؛ وإلا يبقى المسار القياسي مع تسجيل السبب.
- دعم الإعدادات لا يعني أن كل كرت NVIDIA اختُبر فعلياً. توفر الذاكرة وتوافق PyTorch وCUDA ضروريان.

القياس التاريخي لتحسين V8 كان حوالي **0.922%** لزمن الطلب الكامل، أقل من شرط قبول التجربة. نتيجة **18.95%** تخص جزء الرأس فقط. لم نصل إلى 500 توكن/ثانية، وفحص الجودة النهائي بقي غير محسوم.

فحوص المكتبة الحالية تخص الكود والتغليف على CPU؛ نسخة المكتبة بعد التغليف تحتاج اختبار GPU مستقل. راجع [التثبيت والتشغيل](README.md) و[سجل التحقق](docs/validation.md).
